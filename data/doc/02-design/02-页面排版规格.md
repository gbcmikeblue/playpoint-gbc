# 页面排版规格（逐页 P01-P15）

> 全部数值单位 rpx（基准 750）。截图 416px 宽按 ×1.8 换算，属于**视觉还原级估算**，误差 ±4rpx；有设计稿时以设计稿为准。
> 通用约定：页面左右边距 24；卡片圆角 24；卡片间距 20；标题字重 600/700。
> **第二轮补充的 9 个页面（P16-P24）见 [04-补充页面排版规格.md](./04-补充页面排版规格.md)**：票详情/取票、活动详情、打卡点列表、搜索页、通知消息、我玩过的、天梯结果页、城市选择、关于我。

**排序 / 筛选抽屉（第二轮补图确认）**：
- **排序**：底部白面板，3 个全宽选项「综合排序（默认，右侧绿勾）/ 时间最近 / 离我最近」，行高 88，细分隔线；选中即生效并关闭。
- **筛选**：底部白面板；标题居中「深圳市 ▾」可切城市 + 右上 ✕；**只有时间维度**——三个胶囊（本周末 / 一周内 / 一月内）+ 第二行「起始时间」-「终止时间」两个日期输入；底部「重置」（白底描边）+「确定」（黑底绿字）。
- 没有价格/距离筛选：距离由"离我最近"排序承担，价格进详情页看。
- 引导条文案「聊点有意思的 顺便认识有趣的人」为**运营可配**（首轮截图为"看看，最近的人在玩什么"），不写死。
- 分类胶囊来自运营数据（上海「热门/全部/匹克球…」、深圳「跑步/飞盘/躲猫猫…」），前端禁止写死。
- 活动卡可叠加运营角标（封面左上文字，如"疗愈游戏群"）与主理人行（头像 28 + 昵称 24 `#999`）。

## 通用排版约束（所有页面）

1. **自定义导航栏**：全部页面使用 `nav-bar` 组件，`statusBarHeight + 44`，右侧按 `wx.getMenuButtonBoundingClientRect()` 避让，避免与胶囊重叠（P03 详情大图需沉浸式）。
2. **安全区**：所有吸底元素（tabBar、悬浮条、输入区、提交按钮）加 `padding-bottom: env(safe-area-inset-bottom)`。
3. **长内容页**：使用 `scroll-view` 或 `page` 滚动，禁用横向滚动条（`::-webkit-scrollbar { display:none }`）。
4. **图片**：列表图统一 `mode="aspectFill"` + `lazy-load`，封面比例 4:3，头像 1:1。
5. **空/错/载三态**：每个列表页必须实现空状态插画、骨架屏、失败重试。
