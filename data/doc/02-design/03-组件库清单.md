# 组件库清单

原则：**先组件后页面**。页面只做布局与数据拼装，交互细节全部下沉到组件；所有组件带 `custom-class` 外部样式入口，尺寸走 rpx。
命名前缀：业务组件 `pp-`（playpoint），基础组件直接语义命名。

> **实现状态（M0）**：已落地 7 个 base 组件 —— `nav-bar`、`privacy-modal`、`skeleton`、`empty`、`tag`、`avatar`、`badge`；`button`/`cell`/`sheet` 暂用 `mixins.wxss` 的 class（`.btn-primary`/`.btn-dark`/`.btn-ghost`、卡片样式）顶替，M1 首次复用时再抽组件。`biz/` 层全部未开始（M1-M2 按页面逐个补）。下方清单是**目标态**，不是当前代码现状。

## 2. 关键组件契约

### `nav-bar`
| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `title` | string | '' | 居中标题；空则左对齐内容 |
| `mode` | `'normal'\|'immersive'\|'transparent'` | normal | 沉浸式用于详情大图（白字） |
| `back` | boolean | true | 是否显示返回 |
| `scrollTop` | number | 0 | 用于滚动渐变（60→100% 透明白底） |
| slot | `left` / `right` | — | 自定义区域（城市选择、编辑主页） |

> 内部计算 `statusBarHeight` 与胶囊位置，暴露 `navHeight`，页面据此设置 `padding-top`。

### `sheet`
| 属性 | 说明 |
| --- | --- |
| `visible` | 双向绑定 |
| `title` / `subtitle` | 头部文案 |
| `bg` | `'white'\|'mint'`（报名字段为浅绿） |
| `footSlot` | 吸底按钮区 |
| events | `close`、`confirm` |

### `activity-card`
入参：`cover, title, date, week, time, location, price?, status?`；形态 `'horizontal'|'vertical'`；右侧插槽放状态角标。

### `campaign-card`
入参：`sealImg, title, dateRange, images[3], joinerCount, joinerAvatars[3], joined`；点击按钮与点击卡片派发不同事件。

### `quiz-question`
入参：`index, title, desc, options[{level,label,desc}], value, multiple`；事件 `change`。

### `privacy-modal`
入参：`visible, version`；事件 `agree / disagree`；内部禁止点遮罩关闭。

## 4. 复用与禁止事项

- **禁止**在页面里写死颜色，必须用 `app.wxss` 中的 CSS 变量。
- **禁止**在页面里直接 `wx.request`，统一走 `services/`。
- 同一 UI 出现 ≥2 次必须抽组件；`activity-card` 已确定在首页与票夹复用，形态差异用 `mode` 属性解决。
- 组件不做数据请求（除 `chat-input` 发消息这种强交互），保持纯展示 + 事件。
- 所有组件必须提供 `disabled`、`loading`、`empty` 至少一个兜底状态。
