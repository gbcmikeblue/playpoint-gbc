# 设计语言与设计令牌

## 1. 度量基准

截图渲染尺寸为 **416 × 781 px**，对应小程序 750rpx 设计宽度。

```
750 / 416 ≈ 1.803   →  1px(截图) ≈ 1.8rpx
```

设计稿按 **750rpx** 出图，本文所有数值均为 rpx。1rpx ≈ 0.5px@375。

## 2. 色彩令牌

### 2.1 品牌色

| Token | 值 | 用途 |
| --- | --- | --- |
| `--c-brand` | `#00E676` | 主按钮、选中态、Tab 激活、进度 |
| `--c-brand-strong` | `#00C853` | 按钮按下态、渐变尾色 |
| `--c-brand-weak` | `#D7F8DF` | 弹层底色、提示条底色 |
| `--c-brand-ghost` | `#EAFBF0` | 页面浅底、Tag 底色 |
| `--c-brand-ink` | `#0A7D46` | 绿底上的深色文字（少用） |

> 主色为高饱和荧光绿，**只用于可交互元素与状态**，不做大面积背景，避免廉价感。绿底文字统一用 `#111`。

## 3. 字体

微信小程序默认 `PingFang SC / Helvetica Neue`，无需引入字体文件；数字建议 `DIN Alternate`（有则用，无则回退）。

| Token | 字号 | 字重 | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| `--fs-display` | 48rpx | 700 | 1.25 | 弹层大标题、金额 |
| `--fs-h1` | 40rpx | 700 | 1.3 | 页面标题（导航栏内为 34rpx） |
| `--fs-h2` | 32rpx | 600 | 1.35 | 区块标题、卡片标题 |
| `--fs-body` | 28rpx | 400 | 1.55 | 正文、列表主文案 |
| `--fs-sm` | 24rpx | 400 | 1.45 | 说明、时间、副标题 |
| `--fs-xs` | 20rpx | 500 | 1.3 | 角标、标签 |

- 单行省略：标题超长用 `text-overflow: ellipsis`；活动标题允许 2 行（`-webkit-line-clamp: 2`）。
- 价格/人数等数字加粗提权，不做彩色。

## 4. 间距与栅格

| Token | 值 | 用途 |
| --- | --- | --- |
| `--sp-1` | 8rpx | 图文间隙 |
| `--sp-2` | 16rpx | 紧凑间距 |
| `--sp-3` | 24rpx | **页面左右安全边距（基准）**、卡片内边距 |
| `--sp-4` | 32rpx | 区块内间距 |
| `--sp-5` | 48rpx | 区块上下留白 |

- 页面左右统一 **24rpx**；列表卡之间 **20rpx**；区块之间 **32rpx**。
- 首页双 Banner 采用 2:1 分栏，中间缝 16rpx。

## 7. 图标与插画

| 类型 | 规格 | 说明 |
| --- | --- | --- |
| 功能图标 | 40rpx 线性，圆头端点，线宽 3rpx | 首页搜索、消息、返回 |
| TabBar 图标 | 48rpx，选中填充/未选中描边 | 5 项 |
| 分类图标 | 32rpx 线性（🗂 桌游、🏸 羽毛球等） | 筛选胶囊内 |
| IP 插画 | 空状态 400×300；引导角色 320rpx 高 | 统一"绿衣 C 小人 + 白猫"，PNG 透明底 |
| 印章/奖牌 | 圆形 96rpx | 挑战赛卡片左侧印章、奖牌展示 |

- 插画资源需统一交付：`/assets/illustration/{empty-*, ip-*, medal-*}.png`，2x/3x 各一套，单张 ≤80KB。
- 图标统一走 iconfont 或 SVG symbol，禁止散落 PNG。

## 8. 动效

| 场景 | 动效 | 时长/曲线 |
| --- | --- | --- |
| 弹层出现 | 底部上滑 + 遮罩淡入 | 260ms `cubic-bezier(.22,.61,.36,1)` |
| Tab 切换 | 下划指示器滑动 | 200ms ease-out |
| 奖牌获得 | 缩放弹跳 + 光晕 | 600ms |
| 列表加载 | 骨架屏呼吸 | 1200ms 循环 |
| 按钮点击 | 缩放 0.97 | 100ms |

- 遵循 `prefers-reduced-motion` 的等价物：小程序用 `wx.getSystemInfo().enableDebug` 无关，直接提供"减弱动效"开关（P2）。

## 9. 可访问性与兜底

- 正文最小 24rpx（≈12px），不使用 20rpx 承载关键信息。
- 纯图标按钮需带 `aria-label`（小程序用 `aria-label` 属性）与点击热区 ≥88rpx。
- 绿底黑字对比度 ≥ 7:1，符合正文可读要求；灰字 `#999` 仅用于非关键信息。
- 深色模式本期不做，但颜色全部走 CSS 变量，为后续留口子。
