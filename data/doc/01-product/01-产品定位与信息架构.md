## 1. 产品定位

| 项目 | 结论 |
| --- | --- |
| 产品名 | 玩点（暂定名，代号 `PlayPoint`） |
| 一句话定位 | 城市兴趣社交平台：发现同城活动 → 报名参加 → 现场打卡挑战 → 积累奖牌与个人兴趣档案 |
| 核心用户 | 18-35 岁城市青年，有运动/桌游/亲子/逛街等兴趣，需要"找人一起玩" |
| 核心场景 | ① 周末找同城活动并报名 ② 参加线下挑战赛打卡集奖牌 ③ 建立个人兴趣画像（兴趣天梯/MBTI）并被人认识 |
| 差异化 | 兴趣天梯 + MBTI 组成"人设资产"；打卡挑战赛把线下行为沉淀为奖牌；主理人体系驱动内容供给 |
| 商业模式【推断】 | 活动报名抽佣/置顶、主理人会员、品牌广告位（截图中 OPPO 联名横幅）、场地租赁 |
| 视觉风格 | 荧光绿主色 + 手绘插画 + 二次元 3D 人物，年轻、轻社交（风格借鉴，IP 自研） |

### 视觉风格与语气
- 主色为高饱和荧光绿（约 `#00E676`），用于按钮、选中态、Tab 激活、消息角标；
- 插画统一使用**自研** IP 形象（不复用参考产品的绿衣小人/白猫/3D 人物），承担空状态、引导与彩蛋；
- 文案口语化、轻玩梗（"看看最近有什么好玩的""给自己起个昵称"），不照搬参考原文。

## 2. 信息架构（IA）

```
玩点 PlayPoint
├── 粗门（Tab1｜首页/发现）
│   ├── 城市定位选择
│   ├── 全局搜索（俱乐部 / 活动 / 用户）
│   ├── 运营 Banner（城市会玩、主理人宇宙、品牌联名）
│   ├── 活动分类筛选（热门/全部/匹克球/桌游/羽毛球/小众尝鲜/亲子成长/遛遛商场/热血…）
│   ├── 排序 + 筛选（时间/距离/价格…）
│   ├── 活动列表卡片
│   └── 活动详情【推断：截图未覆盖，需补】
│       ├── 活动信息 + 主办方
│       ├── 报名（复用报名信息弹层）
│       └── 票夹生成
├── 打卡（Tab2｜打卡挑战赛）
│   ├── 挑战赛列表（入戏长安 / 九寨沟公益向山…）
│   └── 挑战赛详情
│       ├── Tab：挑战赛 / 通关用时榜
│       ├── 挑战得奖励（奖牌）
│       ├── 报名 → 报名信息弹层
│       └── 打卡提交【推断：截图未覆盖，需补】
├── ＋（Tab3｜发布 FAB，凸起按钮）
│   └── 发布入口面板【推断】：发活动 / 发打卡 / 发影集
├── 消息（Tab4）
│   ├── 通知消息（系统/运营通知）
│   └── 会话列表 → 聊天详情（主理人助理、粗门小助理）
└── 我的（Tab5）
    ├── 主页头部（头像/昵称/关注/粉丝/玩过人数/活动数/个性标签/签名）
    ├── 兴趣天梯测试入口 + 奖牌入口
    ├── 功能宫格（加入的俱乐部 / 成为主理人 / 问问 / 组织活动）
    ├── Tab：我玩过的 / 票夹 / 影集
    │   └── 票夹二级筛选：活动 / 场地 / 租赁 / 打卡；空状态插画
    ├── 编辑主页 → 个人资料页
    │   ├── 基本信息（头像 0/20、昵称、性别、生日、关于我、MBTI）
    │   ├── 报名信息（常用报名信息，N 人）
    │   ├── 协议（用户协议 / 隐私协议）
    │   ├── 手机号
    │   └── 切换账号 / 转发截图
    ├── MBTI 选择（16 型半屏面板）
    └── 兴趣天梯
        ├── 运动兴趣选择（2 列网格 8 项）
        └── 答题页（Lv.1-5 水平题 + 擅长项）→ 生成兴趣天梯
```

## 3. 导航规则

| 层级 | 载体 | 说明 |
| --- | --- | --- |
| L0 | TabBar 5 项 | 粗门 / 打卡 / ＋ / 消息 / 我的；中间为凸起 FAB（非页面） |
| L1 | `navigateTo` | 活动详情、挑战赛详情、个人资料、兴趣天梯、MBTI、聊天详情 |
| L2 | 半屏弹层 | 报名信息填写、MBTI 选择（页面上滑遮罩 + 圆角卡片，非独立页面） |
| 全局 | 隐私授权弹窗 | 首次进入首页时强制弹出，不同意则阻断使用 |

- 弹层与页面可共用组件：`sheet-layout`（顶部圆角 32rpx、右上关闭、底部固定主按钮）。
- 打卡详情底部为**悬浮操作条**（参加/报名按钮），不随内容滚动。
- 聊天详情使用 `scroll-view` 倒序滚动 + 底部输入区吸底。

## 4. 角色与权限

| 角色 | 关键能力 | MVP 是否覆盖 |
| --- | --- | --- |
| 游客 | 浏览首页/活动，触发登录时授权 | 是 |
| 普通用户（探索者） | 报名、打卡、票夹、兴趣天梯、MBTI、消息 | 是（核心） |
| 主理人 | 发起活动、管理报名、群发消息 | P1 |
| 俱乐部管理员 | 建立俱乐部、成员管理 | P2 |
| 平台运营 | Banner/分类/挑战赛配置、内容审核 | P1（后台） |
