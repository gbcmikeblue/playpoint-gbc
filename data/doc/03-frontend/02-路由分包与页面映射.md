# 路由分包与页面映射

约束：微信小程序**主包 ≤ 2MB**，总包 ≤ 20MB，单个分包 ≤ 2MB；**tabBar 页面必须在主包**；`custom-tab-bar/` 必须在主包根目录。

## 1. 分包策略

| 包 | 内容 | 预估体积 | 预下载 |
| --- | --- | --- | --- |
| 主包 `main` | 4 个 Tab 页 + custom-tab-bar + base 组件 + 全局样式 + 登录 | 1.3MB | — |
| `pkg-campaign` | 挑战赛详情、打卡点列表、打卡提交、榜单 | 300KB | 首页停留 2s 后预下载 |
| `pkg-profile` | 个人资料、关于我、取票页、常用报名人、协议、奖牌墙、影集 | 360KB | 无（低频） |
| `pkg-ladder` | 兴趣天梯选择/答题/结果、MBTI | 180KB | 无 |
| `pkg-message` | 聊天详情、通知列表 | 160KB | 进入消息 Tab 时 |
| `pkg-activity` | 活动详情、发布面板、报名成功页、收银台、支付结果、搜索、城市选择 | 360KB | 首页停留 2s 后预下载 |

> 插画资源是体积大头：所有 IP 插画走 **CDN 远程加载**，仅 tabBar 图标与首屏必要图内置，可再省 400KB+。

## 3. app.json 骨架

```jsonc
{
  "pages": [
    "pages/home/index",
    "pages/campaign/list",
    "pages/message/index",
    "pages/mine/index"
  ],
  "subPackages": [
    { "root": "pkg-activity", "pages": ["pages/detail/index", "pages/publish/index", "pages/signup-success/index", "pages/pay/index", "pages/pay-result/index", "pages/search/index", "pages/city/index"] },
    { "root": "pkg-campaign", "pages": ["pages/detail/index", "pages/checkpoints/index", "pages/checkin/index", "pages/rank/index"] },
    { "root": "pkg-profile", "pages": ["pages/edit/index", "pages/about/index", "pages/ticket/index", "pages/signup-info/index", "pages/agreement/index", "pages/medal/index"] },
    { "root": "pkg-ladder", "pages": ["pages/sports/index", "pages/quiz/index", "pages/result/index"] },
    { "root": "pkg-message", "pages": ["pages/chat/index", "pages/notice/index"] }
  ],
  "preloadRule": {
    "pages/home/index": { "network": "all", "packages": ["pkg-campaign", "pkg-activity"] },
    "pages/message/index": { "network": "wifi", "packages": ["pkg-message"] }
  },
  "tabBar": { "custom": true, "list": [
    { "pagePath": "pages/home/index", "text": "玩点" },
    { "pagePath": "pages/campaign/list", "text": "打卡" },
    { "pagePath": "pages/message/index", "text": "消息" },
    { "pagePath": "pages/mine/index", "text": "我的" }
  ]},
  "requiredPrivateInfos": ["getFuzzyLocation"],
  "permission": { "scope.userFuzzyLocation": { "desc": "用于展示附近的活动与挑战赛" } },
  "window": { "navigationStyle": "custom", "backgroundColor": "#FFFFFF" }
}
```

- `tabBar.list` 只声明 4 项（中间 FAB 是 custom-tab-bar 里的视觉元素，不是页面）；`custom: true` 时 list 仍必填，用于 `switchTab` 识别。
- 全局 `navigationStyle: custom`，所有页面统一用 `nav-bar` 组件。

## 4. 自定义 tabBar 要点

```ts
// custom-tab-bar/index.ts
switchTab(e) {
  const { path } = e.currentTarget.dataset
  wx.switchTab({ url: '/' + path })
}
// 每个 tab 页 onShow 里：
this.getTabBar().setData({ selected: 0, msgUnread: store.message.unread })
```
- FAB（第 3 项）不 switchTab，直接 `wx.navigateTo` 发布面板；未登录先触发登录。
- 消息未读角标从 `store.message.unread` 单向流入 tabBar，避免各页重复计算。

## 6. 跳转规范

| 场景 | API | 备注 |
| --- | --- | --- |
| Tab 之间 | `wx.switchTab` | 不可带参数，参数走 store 或 storage |
| 详情/编辑 | `wx.navigateTo` | 保留返回栈，最多 10 层 |
| 报名成功页 | `wx.redirectTo` | 避免返回重复报名 |
| 分享卡片进入 | `wx.navigateTo` + `onLoad` 解析 `scene` | 需 `decodeURIComponent` |

- 所有跳转封装在 `utils/nav.ts`（`toActivity(id)`、`toCampaign(id)`），禁止业务里散写 URL。
