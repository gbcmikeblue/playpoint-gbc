# 发布与对外可见

> 目标：让「不是开发者」的人也能在手机上打开这个小程序。
> 现状：还没有可用的测试/正式后端域名，所以体验版暂时走 Mock 数据（见 `miniprogram/config/env.ts` 的 `trial.mock`）。

## 1. 三种可见范围

| 方式 | 谁能打开 | 有效期 | 需要什么 | 适合场景 |
| --- | --- | --- | --- | --- |
| 预览码 | 扫码的开发者/体验成员 | 25 分钟 | 开发者工具已登录 | 自己调试 |
| **体验版** | 你添加的**体验成员**（按微信号） | 长期，直到被新版本替换 | 上传开发版 + 后台设为体验版 + 加成员 | 给朋友、面试官、评审看 |
| 正式版 | 所有人搜得到 | — | 提审通过并发布 | 真正上线 |

**推荐**：先走体验版，零审核、几分钟就能给别人看。

## 2. 体验版操作步骤

### 2.1 上传开发版

微信开发者工具打开 `miniprogram/` → 右上角「上传」：

- 版本号：`1.0.0`
- 项目备注：`M1 发现-报名-票夹`

上传前确认 `project.config.json` 里的 `appid` 是 `wx932d1c38462f907c`。上传成功后，后台「管理 → 版本管理 → 开发版本」能看到这一版。

### 2.2 设为体验版

[微信公众平台](https://mp.weixin.qq.com) → 管理 → **版本管理** → 开发版本右侧「···」→ **选为体验版**，生成体验版二维码。

### 2.3 添加体验成员

管理 → **成员管理 → 体验成员** → 添加成员，输入对方**微信号**（不是昵称）。

- 体验成员有人数上限，以后台提示为准；个人主体名额较少，超了就只能走正式发布。
- 对方无需是开发者，也不需要把你的小程序加到自己列表里，扫体验版二维码即可。

### 2.4 对方怎么进

- 扫你分享的**体验版二维码**；
- 或微信搜索小程序名 → 进入后右上角「···」→ 打开调试（体验阶段不必须）；
- 部分机型首次打开提示「开发版/体验版」，属正常。

## 3. 目前体验版能体验到什么

- 因为 `trial.mock = true`，接口全部走本地 Mock：首页 → 活动详情 → 报名 → 模拟支付 → 票夹/电子票都能点通；
- 数据只存在各自手机的 storage 里，互相不可见、重启后报名记录仍在；
- 支付是模拟的，不会产生真实交易；
- 「我的 → Mock 接口数据」开关只在开发环境出现，体验版看不到，避免误切到不存在的后端。

## 4. 要正式上线还缺什么

| 项 | 要求 | 现状 |
| --- | --- | --- |
| 后端域名 | 必须 HTTPS，且在国内完成 ICP 备案 | ❌ 只有 `*.playpoint.local` 占位 |
| 服务器域名配置 | 后台「开发管理 → 服务器域名」里把 request/upload/download 域名加白 | ❌ |
| 关闭 Mock | `config/env.ts` 的 `release.mock = false`（已是）+ 确认 `trial` 改回 false | ⚠️ trial 暂开 |
| 类目与资质 | 个人主体可选类目有限，社交/活动报名类目常需企业主体 | ❌ 未选 |
| 隐私协议 | 后台「用户隐私保护指引」声明收集的信息；小程序内协议页可访问 | ⚠️ 占位文案 |
| 审核与发布 | 提交审核 → 通过 → 发布 | ❌ |

**顺序建议**：部署后端（备案域名）→ 关掉 trial 的 mock → 配服务器域名 → 填隐私指引与类目 → 提审。

## 5. 可选：命令行/CI 上传

开发者工具 CLI 可代替手工点「上传」（需先在「设置 → 安全设置」打开服务端口）：

```powershell
& "C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat" upload `
  --project "D:\project\playpoint-gbc\miniprogram" -v 1.0.0 -d "M1 体验版"
```

没有开发者工具的环境（如 GitHub Actions）用 `miniprogram-ci`：后台「开发管理 → 开发设置 → 小程序代码上传」下载密钥，配置 IP 白名单后即可在流水线里上传。
