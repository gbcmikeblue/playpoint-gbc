## 6. 决策记录（ADR 摘要）

| 决策 | 结论 | 理由 |
| --- | --- | --- |
| 框架 | 原生小程序 + TS | 自定义 UI 需求重，跨端收益低 |
| 后端 | NestJS + PostgreSQL | 地理查询 + JSONB 配置 + 团队栈 |
| 聊天 | 轮询（MVP） | 频次低，省一个长连接服务 |
| 打包 | 6 分包 + 插画 CDN | 主包 2MB 硬约束 |
| 支付 | 自绘收银台 + 模拟回调，不接真实网关 | 练手项目无商户号，但要跑通"下单 → 支付 → 出票"完整流程 |
| 品牌 | 不复刻，名称/IP/文案自研 | 练手项目，避免混淆与素材侵权 |
| 地图 | 本期不做可拖动地图 | 打卡点页改纯列表、活动详情地图改静态占位；接口仍返 lat/lng 以便后续接 `<map>` |
| 发布面板 | 只做外观 + 「发活动」占位 | 发布能力属 P2，先保留入口不影响主链路 |
