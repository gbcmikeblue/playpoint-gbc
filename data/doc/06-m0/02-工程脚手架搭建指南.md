## 5. 请求层 `services/request.ts`

```ts
import { env } from '../config/env'
import { appStore } from '../stores/app'

type ApiRes<T> = { code: number; message: string; data: T; traceId?: string }
type Opts = { url: string; method?: 'GET'|'POST'|'PATCH'|'DELETE'; data?: any
              silent?: boolean; auth?: boolean; retry?: number }

let refreshing: Promise<string> | null = null

export async function request<T>(o: Opts): Promise<T> {
  const header: Record<string,string> = { 'content-type': 'application/json' }
  if (o.auth !== false) {
    const t = wx.getStorageSync('cm_token')
    if (t) header.Authorization = `Bearer ${t}`
  }
  const res = await wxRequest<ApiRes<T>>({ url: env.baseURL + o.url, method: o.method ?? 'GET', data: o.data, header, timeout: 10000 })

  if (res.statusCode === 401 && o.auth !== false) {
    refreshing = refreshing ?? doRefresh()
    const token = await refreshing.finally(() => { refreshing = null })
    return request<T>({ ...o, retry: 0 })
  }
  if (res.statusCode !== 200) throw new Error('NETWORK')
  const body = res.data
  if (body.code !== 0) {
    if (!o.silent) wx.showToast({ title: body.message, icon: 'none' })
    throw Object.assign(new Error(body.message), { code: body.code })
  }
  return body.data
}
```

要点：
- 401 用**单例 Promise** 续期，避免并发重复刷新；
- 错误码集中处理，页面只 catch 需要特判的（3001/3002/7002）；
- 所有 URL 走 `services/*.ts`，页面不直接调用。

## 6. 登录 `services/auth.ts` + `stores/user.ts`

```ts
export async function login() {
  const { code } = await wx.login()
  const data = await request<LoginRes>({ url: '/auth/login', method: 'POST', data: { code }, auth: false })
  wx.setStorageSync('cm_token', data.token)
  wx.setStorageSync('cm_refresh', data.refreshToken)
  userStore.setUser(data.user)
  return data
}
```

`app.ts` 启动顺序（**严格按此顺序**）：

```ts
onLaunch() {
  this.initSystemInfo()            // 状态栏/胶囊尺寸 → appStore
  const token = wx.getStorageSync('cm_token')
  const task = token ? this.fetchMe() : login()   // 有 token 先验活
  this.loadConfig()                // /app/config，与本地 version 比对
  return Promise.all([task, this.loadConfig()])
}
```

- `app.ts` 的 `onLaunch` 不阻塞首屏渲染，首页自己等待 store ready（用 `await appStore.ready`）。
- token 存 storage，**不存 store**（避免 setData 泄漏）。

## 8. 隐私弹窗接入

```ts
// utils/privacy.ts
export async function ensurePrivacy(): Promise<boolean> {
  const cfg = appStore.config
  const agreed = wx.getStorageSync('cm_privacy_version')
  if (agreed && agreed === cfg.agreementVersion) return true
  const ok = await new Promise<boolean>(res => {
    appStore.setShowPrivacyModal({ resolve: res })   // 页面渲染 privacy-modal
  })
  if (ok) {
    wx.setStorageSync('cm_privacy_version', cfg.agreementVersion)
    request({ url: '/app/privacy-consent', method: 'POST',
              data: { docVersion: cfg.agreementVersion, action: 'agree' }, silent: true })
  }
  return ok
}
```

- 首页 `onShow` 第一行 `await ensurePrivacy()`，未同意则阻断滚动与 tabBar 点击。
- "不同意"给二次确认（参考微信规范：可退出）。

## 9. base 组件最小实现要点（10 个）

| 组件 | 必须支持的属性 | 实现要点 | 工时 |
| --- | --- | --- | --- |
| `nav-bar` | `title/mode/back/scrollTop` | 计算 `statusBarHeight` + 胶囊右边界；`immersive` 用白色文字 + 滚动渐白 | 0.4d |
| `sheet` | `visible/title/subtitle/bg` | 遮罩 + 底部圆角 40 + 上滑动效；`catchtouchmove` 防穿透 | 0.3d |
| `button` | `type/loading/disabled/block` | 主绿(黑字)/黑(白字)/次(描边)/禁用灰；`hover-class` 缩放 0.97 | 0.2d |
| `cell` | `label/value/arrow/note` | 行高 112、分割线左缩进、右侧 `›` | 0.1d |
| `tag` | `size/active` | 胶囊 999、24 号字、选中绿底黑字 | 0.1d |
| `avatar` | `src/size/ring` | 圆形、白描边 4、无图时用占位 IP | 0.1d |
| `badge` | `count/dot` | 红点 32、`99+` 截断 | 0.1d |
| `empty` | `image/title/desc/actionText` | 插画 400×300 + 双行文案 + 可选按钮 | 0.1d |
| `skeleton` | `type` | 列表/卡片/详情三套；`animation: breath 1.2s infinite` | 0.2d |
| `privacy-modal` | `visible` | 620 宽白卡 + 协议蓝字 + 双按钮；禁止点遮罩关闭 | 0.2d |

> **M0 实际只做了 7 个**：`nav-bar`、`privacy-modal`、`skeleton`、`empty`、`tag`、`avatar`、`badge`。上表中的 `button`/`cell`/`sheet` 先用 `mixins.wxss` 的 `.btn-primary` / `.btn-dark` / `.btn-ghost` 与卡片 class 顶替，M1 真正复用时再抽成组件（避免为"清单完整"写没人用的代码）。
>
> 验收方式：`pages/dev/components` 把已实现的组件与 class 各渲染 2-3 个状态，逐项对照 `02-design/02`。
