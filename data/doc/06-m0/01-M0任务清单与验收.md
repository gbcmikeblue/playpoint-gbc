# M0 任务清单与验收

> M0 = **设计基线周**。目标不是做功能，而是把"后面 9 周不会返工"的地基打完。
> 上级计划见 [05-delivery/01-迭代计划与里程碑.md](../05-delivery/01-迭代计划与里程碑.md) 第 2 节。
> 本文件配套：`02-工程脚手架搭建指南` / `03-依赖与版本清单` / `04-数据库DDL与种子数据` / `05-接口契约冻结清单`。

## 1. M0 的一句话目标

> **到第 5 个工作日结束，任何人拉下代码就能真机跑通「启动 → 隐私弹窗 → 微信登录 → 首页 mock 列表」，并且数据库、接口文档、样式令牌三件套齐备。**

## 2. 四条交付线

| 线 | 负责人角色 | 核心产出 | 详细文档 |
| --- | --- | --- | --- |
| A 工程 | 前端 A | 脚手架、分包、请求层、登录、CI | `02-工程脚手架搭建指南.md` |
| B 设计系统 | 前端 B | 设计令牌、7 个 base 组件、组件演示页 | `02-design/01`、`02-design/03` |

## 5. 出口标准（逐条勾，缺一不可）

### 5.1 工程

- [ ] 冷启动到首页可交互 ≤ **2.5s**（4G、中端机），主包 ≤ **1.5MB**
- [ ] 4 个 Tab 可切换，中间 FAB 弹出发布占位面板
- [ ] `tsc --noEmit` 与 `eslint` 零 error
- [ ] CI 能产出体验版二维码，扫码可安装

### 5.2 登录与合规

- [ ] 真机微信登录成功，token 写入 storage，杀进程重启免登录
- [ ] token 过期自动续期，用户无感
- [ ] 首次进入弹隐私弹窗，点"不同意"阻断；点"同意"后 `privacy_consent` 有记录（含版本号、时间）
- [x] 不依赖定位权限：城市由用户手选、默认深圳市，`app.json` 不声明 `requiredPrivateInfos`（`getFuzzyLocation` 需后台开通，见 `03-frontend/01` §4.3），首页无授权也能渲染

### 5.3 数据

- [ ] `prisma migrate` 可在空库一键建 **10 张表**
- [ ] 种子数据含：2 城市、9 分类、2 活动（1 免费 1 付费）、1 挑战赛 + 3 打卡点、1 用户、1 待验票
- [ ] 关键唯一索引存在（`activity_signup(activity_id,user_id) WHERE status IN (0,1)`、`pay_order.order_no`、`campaign_checkpoint(campaign_id,sort)`）

### 5.4 契约

- [ ] Swagger `/docs` 可访问，**15 个接口**全部可 Try it out
- [ ] `npm run gen:types` 生成前端类型，字段与文档一致
- [ ] mock 数据与真实响应**同构**（切开关不改页面代码）
- [ ] 契约打 tag `contract-v1.0`，此后改动走变更流程

### 5.5 设计系统

- [ ] `variables.wxss` 与 `02-design/01` 数值一致（抽查 10 项）
- [ ] 10 个 base 组件在 `pages/dev/components` 全部可见，且支持 `custom-class`
- [ ] 荧光高亮、吸底安全区两个公共类可用

## 6. M0 明确不做（防蔓延）

| 不做 | 原因 | 何时做 |
| --- | --- | --- |
| 任何业务页面（首页除外） | 属 M1-M3 | 按里程碑 |
| 真实活动数据 / 运营后台 | 种子数据够用 | M4 |
| 可拖动地图 | 已定降级 | 不做 |
| 微信支付 | 已改为模拟 | 不做 |

| 性能优化专项 | 先保功能 | M4 |
